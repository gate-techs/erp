## 📖 2. دفاتر اليومية (Journals)
- [ ] **أنواع الدفاتر المحاسبية:**
  - [ ] دفتر مبيعات (Sales Journal)
  - [ ] دفتر مشتريات (Purchase Journal)
  - [ ] دفتر سندات قبض نقدية / بنكية (Cash / Bank Receipt Journal)
  - [ ] دفتر سندات صرف نقدية / بنكية (Cash / Bank Payment Journal)
  - [ ] دفتر العمليات البنكية (Bank Journal)
  - [ ] دفتر قيود عامة وتسويات (General Operations Journal)
- [ ] **الترقيم والتسلسل:**
  - [ ] رقم تسلسلي مستقل وتلقائي لكل دفتر محاسبي (Sequence Numbering Per Journal)
  - [ ] كود مميز لكل دفتر (Journal Short Code)
  - [ ] تحديد حساب افتراضي لكل دفتر (Default Debit/Credit Account)

## ✍️ 3. القيود اليومية (Journal Entries)
- [ ] **رأس القيد (Entry Header):**
  - [ ] التاريخ (Date)
  - [ ] البيان / الوصف العام (Description / Narration)
  - [ ] المرجع الخارجي (Reference Number)
  - [ ] الكيان المحاسبي التابع له (Accounting Entity)
  - [ ] الدفتر المحاسبي التابع له (Journal)
  - [ ] العملة وسعر الصرف (Currency & Exchange Rate)
- [ ] **تفاصيل وأسطر القيد (Entry Lines):**
  - [ ] اختيار الحساب المالي (Account Selection)
  - [ ] مدين (Debit) / دائن (Credit)
  - [ ] مركز التكلفة (Cost Center / Analytics)
  - [ ] الشريك / الطرف الخارجي (Partner: Customer / Vendor)
  - [ ] البيان الخاص بكل سطر (Line Description)
- [ ] **التحقق وقواعد الأعمال (Validation & Business Rules):**
  - [ ] التحقق التلقائي والصارم أن إجمالي المدين = إجمالي الدائن (Balanced Entry)
  - [ ] منع حفظ أسطر بقيم سالبة أو صفرية في المدين والدائن معاً
- [ ] **دورة حياة وحالات القيد (Entry Statuses):**
  - [ ] مسودة (Draft)
  - [ ] مرحّل (Posted)
  - [ ] ملغي / معكوس (Cancelled / Reversed)
- [ ] **حماية القيد المُرَحّل (Post Protection):**
  - [ ] منع تعديل أو حذف القيد بعد ترحيله نهائياً
  - [ ] إمكانية إلغاء القيد عبر إنشاء قيد عكسي تلقائي (Reverse Entry)
  - [ ] فحص تواريخ الإقفال لمنع إنشاء أو ترحيل قيود قبل تاريخ القفل

---

## 📊 4. دفتر الأستاذ والتقارير المالية (Ledger & Financial Reports)
- [ ] **دفتر الأستاذ العام (General Ledger):**
  - [ ] فلترة حسب الفترة، الكيان، الحساب، ومركز التكلفة
  - [ ] عرض الحركات المدينة والدائنة والرصيد التراكمي
- [ ] **كشف حساب تفصيلي (Account Statement):**
  - [ ] كشف حساب عميل / مورد / حساب عام
  - [ ] رصيد افتتاحي + حركات + رصيد ختامي
  - [ ] إمكانية التصدير (PDF / Excel) والطباعة
- [ ] **ميزان المراجعة (Trial Balance):**
  - [ ] ميزان المراجعة بالمجاميع والأرصدة
  - [ ] خيارات العرض (قبل وبعد قيود الإقفال)
- [ ] **قائمة الدخل - الأرباح والخسائر (Income Statement / P&L):**
  - [ ] الإيرادات - تكلفة المبيعات = مجمل الربح
  - [ ] المصروفات التشغيلية والإدارية
  - [ ] صافي ربح / خسارة الفترة
- [ ] **الميزانية العمومية (Balance Sheet):**
  - [ ] الأصول (متداولة وغير متداولة)
  - [ ] الخصوم (متداولة وغير متداولة)
  - [ ] حقوق الملكية
  - [ ] التحقق من توازن المعادلة المحاسبية (الأصول = الخصوم + حقوق الملكية)
- [ ] **تقرير حركة الحسابات (Account Activity Report):**
  - [ ] ملخص التحركات المالية السريعة وتدفق العمليات

## 🎯 5. الأرصدة الافتتاحية (Opening Balances)
- [ ] **واجهة إدخال أرصدة أول المدة:**
  - [ ] إدخال الأرصدة الافتتاحية للحسابات الرئيسية والفرعية
  - [ ] إدخال أرصدة العملاء والموردين وبطاقات الشركاء
  - [ ] إدخال أرصدة الخزائن والبنوك
- [ ] **القيد الافتتاحي (Opening Entry):**
  - [ ] توليد قيد افتتاحي متوازن تلقائياً بتاريخ بداية النشاط أو بداية السنة المالية
  - [ ] معالجة أي فروق مؤقتة في حساب وسيط (حساب الأرصدة الافتتاحية)

## 🤝 6. الضرائب والعملاء والموردون (Partners & Taxes)
- [ ] **الشركاء (Partners):**
  - [ ] توحيد سجلات العملاء والموردين كـ Partners
  - [ ] الرقم الضريبي، السجل التجاري، وبيانات الاتصال
  - [ ] ربط العميل بحساب العملاء (Accounts Receivable)
  - [ ] ربط المورد بحساب الموردين (Accounts Payable)
- [ ] **الضرائب والرسوم (Taxes & VAT):**
  - [ ] تعريف أنواع الضرائب ونسبها (ضريبة القيمة المضافة 15%، 0%، معفاة)
  - [ ] تحديد حساب ضريبة المخرجات (ضريبة المبيعات المحصلة)
  - [ ] تحديد حساب ضريبة المدخلات (ضريبة المشتريات المدفوعة)
  - [ ] تقرير الإقرار الضريبي لحساب صافي الضريبة المستحقة / القابلة للاسترداد

---

## 🔄 7. دورة المستندات والتكامل الآلي (Document Cycles & Auto-Posting)
- [ ] **فواتير المبيعات (Sales Invoices):**
  - [ ] ترحيل فاتورة المبيعات آلياً ← قيد مبيعات (مدين: العميل/الصندوق/البنك | دائن: المبيعات + ضريبة القيمة المضافة)
- [ ] **فواتير المشتريات (Purchase Invoices):**
  - [ ] ترحيل فاتورة المشتريات آلياً ← قيد مشتريات (مدين: المشتريات/المخزون + الضريبة | دائن: المورد/الصندوق/البنك)
- [ ] **سندات القبض (Payment Receipts):**
  - [ ] إنشاء سند قبض ← توليد قيد قبض آلي (مدين: الخزينة/البنك | دائن: العميل/الحساب المستفيد)
- [ ] **سندات الصرف (Payment Vouchers):**
  - [ ] إنشاء سند صرف ← توليد قيد صرف آلي (مدين: المورد/المصروف | دائن: الخزينة/البنك)
- [ ] **التحويلات المالية (Internal Transfers):**
  - [ ] تحويل نقدي بين الخزائن والبنوك (Transfer between Bank & Cash)
  - [ ] قيد تحويل وسيط أو مباشر لمنع ازدواجية الحسابات

## 🏦 8. الخزائن والبنوك والتسويات (Treasury, Banks & Reconciliations)
- [ ] **إدارة الخزائن والحسابات البنكية:**
  - [ ] تعريف الخزائن النقدية وربطها بأمين الخزينة وحساب الأستاذ
  - [ ] تعريف الحسابات البنكية، الآيبان (IBAN)، وسويفت كود (SWIFT)
- [ ] **التسوية البنكية (Bank Reconciliation):**
  - [ ] استيراد كشف الحساب البنكي (Bank Statement Import)
  - [ ] مطابقة القيود المسجلة بالنظام مع كشف الحساب البنكي
  - [ ] إثبات المصروفات والعمولات البنكية وأرباح الودائع
- [ ] **مطابقة المدفوعات والتحصيلات (Payment Matching):**
  - [ ] تسوية وتخصيص سندات القبض مع فواتير المبيعات
  - [ ] تسوية سندات الصرف مع فواتير المشتريات
