# ALA ORBIT ERP

نظام ERP لإدارة المؤسسات التعليمية والحضانات. التطبيق مبني بـ Laravel 12 وPHP 8.2، ومقسّم إلى موديولات مستقلة تغطي الموارد البشرية، الحسابات، المخزون، الإدارة الأكاديمية، بوابة الموظفين، وغيرها. واجهة الويب مبنية بـ Blade وVite، ويوجد غلاف Capacitor لتطبيق الهاتف.

## المتطلبات

- PHP 8.2 أو أحدث مع امتدادات Laravel المطلوبة.
- Composer.
- Node.js وnpm.
- قاعدة بيانات مدعومة من Laravel؛ الإعداد الحالي يستخدم MySQL بحسب `.env` المحلي.

## تشغيل سريع

```bash
composer install
npm install
```

جهّز ملف `.env` محليًا، واضبط بيانات قاعدة البيانات ومفتاح التطبيق، ثم:

```bash
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

يُفضّل تشغيل الأوامر من جذر المشروع. لا ترفع `.env` أو مفاتيح الخدمات إلى Git. راجع [دليل الإعداد](docs/setup.md) للتفاصيل وملاحظات التشغيل.

## نقاط مهمة

- واجهة الويب المحمية تتطلب تسجيل الدخول؛ تعريف المسارات الأساسية في `routes/web.php`، وموديولات Laravel Modules تضيف مساراتها من داخل كل موديول.
- الوحدات المفعّلة حاليًا محددة في `modules_statuses.json`.
- لا يظهر في الشيفرة الحالية نظام SaaS لإدارة باقات واشتراكات المؤسسات أو فوترة الاشتراك. توجد استخدامات لكلمة اشتراك بمعنى رسوم الطلاب، واشتراكات Push/النشرة البريدية، لكنها ليست اشتراكات المنتج. التفاصيل في [وثيقة الاشتراكات](docs/subscriptions.md).
