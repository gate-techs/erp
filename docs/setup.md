# الإعداد والتشغيل المحلي

## البرامج المطلوبة

| البرنامج | الإصدار أو الاستخدام |
|---|---|
| PHP | 8.2+ |
| Composer | تثبيت اعتماديات PHP |
| Node.js وnpm | بناء أصول الواجهة عبر Vite |
| MySQL أو قاعدة متوافقة مع Laravel | تخزين بيانات التطبيق |

اعتماديات PHP الأساسية موضحة في `composer.json`، ومنها Laravel 12 وLaravel Modules وSpatie Permission وYajra DataTables. اعتماديات الواجهة موضحة في `package.json`.

## التثبيت

1. ثبّت اعتماديات المشروع:

   ```bash
   composer install
   npm install
   ```

2. أنشئ `.env` محليًا من إعداد مناسب لبيئتك. لا يوجد `.env.example` في المستودع حاليًا، لذلك لا تنسخ بيانات `.env` الخاص بجهاز آخر ولا تضع أسرارًا في Git.

3. اضبط `APP_URL` واتصال قاعدة البيانات (`DB_*`) في `.env`، ثم أنشئ مفتاح التطبيق:

   ```bash
   php artisan key:generate
   ```

4. شغّل ترحيلات قاعدة البيانات والبذور:

   ```bash
   php artisan migrate --seed
   ```

5. ابنِ ملفات الواجهة وشغّل الخادم:

   ```bash
   npm run build
   php artisan serve
   ```

افتح العنوان الذي يعرضه `artisan serve`. للتطوير مع Vite استخدم `npm run dev` في نافذة أخرى. يوجد أيضًا سكربت Composer باسم `dev` يشغّل Laravel وqueue وPail وVite معًا؛ يتطلب ذلك أن تكون أدواته متاحة محليًا.

## إعدادات البيئة

- `APP_KEY`: مفتاح Laravel.
- `APP_URL`: عنوان التطبيق.
- `DB_CONNECTION` و`DB_HOST` و`DB_PORT` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD`: اتصال قاعدة البيانات.
- إعدادات البريد والتخزين والـ queue بحسب الخدمات التي ستستخدمها.
- إعداد AI اختياري؛ يمكن إدارة مزود الذكاء الاصطناعي من `/settings/ai`. راجع `Modules/AI/README.md` لمتغيرات المزود الاحتياطية.

لا تستخدم بيانات قاعدة الإنتاج في بيئة التطوير. ملفات SQL الموجودة في المشروع قد تكون نسخًا تشغيلية؛ افحص مصدرها ومحتواها قبل استيرادها.

## قاعدة البيانات والصلاحيات

توجد ترحيلات وبذور عامة في `database/`، وترحيلات وبذور خاصة بكل موديول في مجلداته. عند تفعيل موديول جديد راجع ترحيلاته وبذوره وسياسات الصلاحيات الخاصة به قبل تشغيله على قاعدة بيانات قائمة.

## بناء تطبيق الهاتف

المشروع يحتوي إعداد Capacitor في `capacitor.config.json`، ومعرّف التطبيق `com.gtaps.alaorbit` واسمه `ALA ORBIT`. الإعداد الحالي يوجّه التطبيق إلى بوابة ويب مستضافة، و`webDir` مضبوط على `mobile-app-shell`. هذا غلاف ويب وليس تطبيقًا أصليًا مستقلًا عن الخادم. ملفات Android وiOS موجودة في `android/` و`ios/`.

## استكشاف الأخطاء

- خطأ اتصال قاعدة البيانات: راجع قيم `DB_*` وتأكد أن خدمة قاعدة البيانات تعمل.
- تغييرات الواجهة لا تظهر: شغّل `npm run build` للإنتاج أو `npm run dev` للتطوير.
- موديول غير ظاهر: تحقق من `modules_statuses.json` ومزود الخدمة والمسارات والترحيلات الخاصة به.
- بعد تغيير autoload أو تعريفات Composer: شغّل `composer dump-autoload`.
