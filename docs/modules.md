# دليل الموديولات

الوحدات التالية مفعّلة بحسب `modules_statuses.json`. الوصف يلخص ما يظهر من أسماء الوحدة وملفاتها؛ راجع المسارات والواجهات داخل الوحدة لمعرفة تفاصيل الوظائف الحالية.

| الوحدة | النطاق |
|---|---|
| `Academic` | الإدارة الأكاديمية للمؤسسات التعليمية: سنوات ومراحل وفصول ومواد وخطط أسبوعية وشهرية. |
| `Accounting` | الحسابات والقيود والتقارير المالية ومساعد مالي مدعوم بالذكاء الاصطناعي. |
| `AccessControl` | الأدوار والصلاحيات والتحكم في الوصول. |
| `AI` | واجهة موحدة لمزودي الذكاء الاصطناعي؛ إعدادها في `/settings/ai`، وتوثيقها التفصيلي في `Modules/AI/README.md`. |
| `AuditLog` | تسجيل ومراجعة أنشطة النظام. |
| `CRM` | وظائف إدارة علاقات العملاء. |
| `EmployeePortal` | بوابة الموظفين، بما فيها خدمات وواجهات البوابة وإشعاراتها. |
| `HR` | الموارد البشرية وشؤون الموظفين والتوظيف وتخطيط القوى العاملة. |
| `Inventory` | إدارة المخزون. |
| `Nursery` | وظائف تشغيل وإدارة الحضانة. |
| `Settings` | إعدادات النظام وخدمات مثل تفضيلات الإشعارات واشتراكات Push. |
| `SiteManagement` | تظهر الوحدة في `modules_statuses.json` وخرائط Composer؛ افحص مجلدها لمعرفة الوظائف المتاحة. |
| `Tasks` | إدارة المهام. |

## خريطة الملفات

- تعريف الوحدة ومزودها: `Modules/<Name>/module.json`.
- مساراتها: `Modules/<Name>/routes/`.
- منطق الخادم: `Modules/<Name>/app/`.
- واجهاتها وترجماتها: `Modules/<Name>/resources/`.
- تغييرات قاعدة البيانات: `Modules/<Name>/database/migrations/`.
- بيانات بدء الوحدة: `Modules/<Name>/database/seeders/`.
- حالة التفعيل: `modules_statuses.json`.

## ملاحظات التكامل

- يستخدم المشروع `nwidart/laravel-modules`، وتُدمج ملفات Composer الخاصة بالوحدات عبر إعداد `wikimedia/composer-merge-plugin`.
- تستخدم الصلاحيات حزمة `spatie/laravel-permission`؛ لا تعتمد على إخفاء عناصر الواجهة وحده لحماية الوظائف، بل تحقق من الصلاحية على الخادم أيضًا.
- وحدة AI توفر خدمة موحدة؛ إعداد مفاتيح المزود وإرشادات استخدامها موثقة في `Modules/AI/README.md`.
